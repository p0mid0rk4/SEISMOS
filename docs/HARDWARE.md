# Аппаратная часть СЕЙСМОС

Документ описывает датчики, узлы сбора, сеть и рекомендации по монтажу.

## 1. Сейсмический датчик GS-20DX

Вертикальный геофон с собственной частотой 4.5 Гц — классический
чувствительный элемент сейсморазведки, хорошо подходящий для охраны
периметра.

| Параметр | Значение |
|---|---|
| Собственная частота | 4.5 Гц |
| Сопротивление катушки | 375 Ом |
| Чувствительность | 28.8 В/(м/с) |
| Коэффициент затухания (разомкнутая обмотка) | 0.56 |
| Масса подвижной части | 11 г |
| Максимальный наклон | 3° |
| Паразитный резонанс | 240 Гц |
| Рабочая температура | −40…+80 °C |

Геофон **пассивен**: он не требует питания на периметре и не содержит
электроники, подверженной климатическому износу. Это ключевое
преимущество для протяжённых участков.

### Принцип работы

Геофон преобразует скорость смещения грунта в напряжение. Передаточная
функция по скорости — второго порядка:

```
H(s) = S · s² / (s² + 2·ζ·ω₀·s + ω₀²)
```

где `ω₀ = 2π·f₀`, `ζ` — затухание, `S` — чувствительность. Выше собственной
частоты отклик по скорости стремится к единице (полка), ниже — существенно
подавляется. Именно поэтому полоса обработки начинается с 5 Гц.

## 2. Узел сбора данных

Узел обслуживает группу геофонов: оцифровывает сигнал, нормирует его и
передаёт по сети.

- **АЦП** — 24-битный ADS1256 (8 каналов), подключается по SPI.
  Мультиплексор последовательно переключает каналы, что реализует опрос
  цепочки «один за другим».
- **Нормировка** — напряжение переводится в скорость (м/с) делением на
  чувствительность и далее в мкм/с.
- **Питание** — PoE (IEEE 802.3af/at): один кабель несёт и данные, и
  питание, что убирает необходимость отдельной линии электропитания вдоль
  периметра.
- **Транспорт** — UDP. Формат пакета:
  `magic(4)="SMS1" + sensor_id(2) + seq(4) + ts(8) + n(2) + отсчёты(int16)`.

### Схема узла

```
 GS-20DX ─┐
 GS-20DX ─┼─► мультиплексор ─► ADS1256 ─► МК/Одноплатник ─► Ethernet (PoE)
 GS-20DX ─┘      (SPI)          (SPI)      (нормировка,
                                            упаковка UDP)
```

## 3. Цепочка датчиков

Датчики одной цепочки опрашиваются последовательно один за другим.
Порядок задаётся полем `chain_index` в конфигурации и соответствует
физической раскладке геофонов вдоль периметра. `ChainReader` циклически
считывает блоки со всех датчиков цепочки и формирует единый поток
`ChainSample`.

Такая организация:

- снижает число узлов сбора (один узел на группу датчиков);
- упрощает кабельную разводку;
- позволяет точно сопоставлять событие с местом на периметре.

## 4. Сеть и магистраль

- **Физическая среда** — витая пара (100BASE-TX); допускается совмещение
  данных и питания PoE в одном кабеле.
- **Топология** — «звезда» от коммутатора на КПП к узлам сбора; для
  протяжённых объектов возможна оптическая магистраль между сегментами.
- **Длина сегмента** — до 100 м по витой паре без повторителей.

## 5. Монтаж

### Установка геофона

1. Выбрать точку в грунте на расстоянии 0.3–1.0 м от ограждения.
2. Пробурить/пробить лунку глубиной 0.3–0.5 м, установить геофон
   вертикально, обеспечить плотный контакт с грунтом.
3. Проверить наклон (не более 3°) и ориентацию (вертикальная ось).
4. Загерметизировать ввод, уложить кабель в грунт или защитный лоток.

### Размещение узлов сбора

- Узел — в шкафу или герметичном боксе, защищённом от осадков.
- PoE-коммутатор — на КПП или в промежуточном шкафу.
- Длина линии SPI от АЦП до геофонов — минимальна; аналоговые линии
  экранированы и разведены вдали от силовых кабелей.

### Рекомендации по выбору рубежа

Для объектов с мягким ограждением (сетка, профлист, штакетник) достаточно
сейсмического рубежа на ограждении. Для монолитных ограждений (бетон,
кирпич) сейсмический рубеж дополняют противоподкопным и контролем подхода;
при отсутствии полосы отчуждения — сочетают с активными ИК-барьерами.

| Ограждение | Полоса отчуждения | Рекомендуемый состав |
|---|---|---|
| Мягкое | есть | сейсмика на ограждении + подход + противоподкоп |
| Мягкое | нет | сейсмика на ограждении + ИК-барьер + противоподкоп |
| Монолитное | есть | сейсмика по верху/в грунте + подход |
| Монолитное | нет | ИК-барьер + противоподкоп |
| Без ограждения | есть | сейсмика в грунте |

## 6. Обслуживание

- **Геофоны** — периодическая проверка наклона и плотности контакта с
  грунтом; электроника отсутствует, отказов мало.
- **Узлы сбора** — контроль целостности PoE-линии, состояния бокса,
  температуры.
- **Сеть** — контроль потерь UDP-пакетов (счётчик `seq` в пакете) и
  времени последнего пакета (`last_seen`).

## 7. Диагностические признаки неисправностей

| Симптом | Вероятная причина |
|---|---|
| Датчик «не на связи» | обрыв линии, отказ PoE, потеря питания узла |
| Постоянный высокий фон | плохой контакт геофона с грунтом, наводки |
| Ложные срабатывания | сильный ветер/дождь; подстроить `cfar_alpha` |
| Нет реакции на воздействие | неверная ориентация геофона, обрыв канала |
| Пропуски в потоке | перегрузка сети, потери UDP-пакетов |
